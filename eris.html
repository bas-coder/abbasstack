cTrader Open API

Read-only account access

Eris uses Open API for balance, equity, and unrealized P&L. Scope: Account info only. No trading via Open API.

Who uses it?

Only the account owner. No third-party users. No public sign-up.

What data is read?

Balance, equity, net unrealized P&L, and open position count.

How does it trade?

Orders go through FIX on the same demo account. Not through Open API.

Why Open API?

FIX gives positions and prices. Open API gives cash balance for true equity.

Broker

IC Markets demo via cTrader. Account used for research only.

Hosting

Private Azure VM. Dashboard for owner access only.
